# Subtitle Edit - Traducere în Limba Română (v5.x)

Acest proiect conține fișierul de localizare actualizat `Romanian.json` pentru noul format introdus în **Subtitle Edit Versiunea 5**. 
Traducerea a fost verificată și testată integral pe versiunea **v5.3.0-portabilă**.

## 🚀 Cum se instalează?

1. Descarcă fișierul `Romanian.json` din acest proiect.
2. Deschide folderul unde ai instalat Subtitle Edit (sau folderul versiunii portabile).
3. Accesează folderul numit `Languages`.
4. Copiază fișierul `Romanian.json` acolo (înlocuiește-l pe cel vechi, dacă există).
5. Deschide programul, mergi la **Options** -> **Choose language** și selectează **Română**.
